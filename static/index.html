Why apply LoRA to Qwen2.5-VL?

VLMs contain billions of parameters. Standard visual encoders and projection gates consume enormous memory. By targeting the linear attention heads (Q, K, V, O) with Low-Rank Adapters, we preserve spatial and semantic alignment while restricting weight updates to only 0.65% (about 45M parameters). This allows fine-tuning on a single consumer GPU (24GB VRAM) instead of requiring multi-GPU node clusters.
